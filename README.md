# Pinner Dental Care — concept redesign

A concept redesign for Pinner Dental Care, a private dental practice at 3 Barters Walk, Pinner HA5 5LU.

**Live preview: https://plainset.github.io/pinner-dental-care-demo/**


Dentistry is GDC-regulated, so this build makes no clinical claim, no outcome promise and no superlative, uses no before-and-after imagery, quotes no price, and never attaches "specialist" to a named individual. Qualifications are reproduced exactly as published.


---

## What this is

An unsolicited **concept redesign**, built by [Plainset](https://github.com/Plainset) as a
demonstration. **It is not Pinner Dental Care's website**, it is not affiliated with or endorsed by them,
and it is not published at their own domain.

Every fact on these pages was taken from Pinner Dental Care's own published sources and is recorded, with
its source, in [`BUILD_BRIEF.md`](BUILD_BRIEF.md). Claims that could not be verified are
listed there under **Do Not Claim** and were deliberately left out. Every photograph is the
business's own.

If you are Pinner Dental Care and you would like this taken down, open an issue on this repository or get
in touch and it will be removed.

## How it was built

Plain static HTML, CSS and JavaScript. No framework, no build step, no dependencies, no
tracking, no cookies.

| File | What it holds |
|---|---|
| [`BUILD_BRIEF.md`](BUILD_BRIEF.md) | Every fact used, its source, and the do-not-claim list |
| [`QA_REPORT.md`](QA_REPORT.md) | Contrast, image-upscale, overflow and accessibility results |
| [`PIPELINE_STATUS.md`](PIPELINE_STATUS.md) | Current state and open questions |

Checked at 320, 390, 768, 1024, 1440 and 1920px for contrast, image upscaling, text overflow,
keyboard access and reduced-motion behaviour.
